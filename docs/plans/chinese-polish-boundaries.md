# 中文润色语义边界与评测

跟踪：[Issue #39](https://github.com/isecret/MemoEcho/issues/39)。日期：2026-11-10。

本轮在本地 #38 接续合并修复上继续优化。范围是固定润色 Prompt、合成评测与现有解析／空结果处理的回归；不增加设置项、生产环境第二次模型请求、客户端正则语义编辑或持久化历史。根目录 README 不改。

## 已确认的口径

用户于本轮明确选择：

- 整段明确只有无语义停顿、清理后没有正文时，模型返回合法 `plain_text` JSON，`text` 为 `""`、`correction_applied` 为 false。应用沿用 `llmEmptyResponse` 错误：不注入、不自动重试、不进入翻译、不清除原转写，允许手动恢复。不新增静默成功或取消状态。
- 独立回应“嗯”“嗯，可以”、疑问、引用和“唉”等感叹继续保留；不确定是否有语义时保留，不机械归为纯赘词。
- 普通正文的“换行、逗号、加引号、标题是…”保留为正文，本次不新增排版指令。自然补标点与原有列表结构继续使用，不能借此删词。已确认的技术符号和局部技术格式还原不变。

## Prompt 调整

1. 明确否定／条件／量词的作用范围，保留人物、对象、顺序、数量关系和不确定性；编号前导零、正负号、小数点及单位不能丢失，相对日期不擅自换算。
2. 未完成句保留已说内容，不替用户补全；保留语气、方言和中英混输，辅助上下文不能补出未口述事实。
3. 情绪、强调、引用与独立语义的保留优先于普通去重。“好好好，你说得都对，我不争了”“行了行了，别再说了”保留；无情绪或新信息的“好的好的”等普通回应仍合并一次。
4. 明确反悔不只靠关键词命中。“算了、还是、先不了、不用了”结合前后文可表示撤回本次表达。只编辑明确指向的局部，采用最终明确意图；保留时间、对象和条件，不能标记改口却继续保留已撤回内容。
5. 历史叙述、引用、假设、普通对比和无撤回含义的“算了”不套用改口删除；#38 接续合并及技术文本规则保留。

## 用例与断言

新增 [chinese-polish.json](../../scripts/fixtures/chinese-polish.json) 共 45 个合成场景：改口／情绪／纯赘词／普通排版、否定条件、数字单位约数、时间与编号、未完成句、方言叠词、中英混输、上下文冲突、枚举与普通序数。反悔与情绪重点场景在每种 profile 下重复 3 次，其余默认一次。

评测使用基础提示词与合成术语／窗口参考两种 profile；带 `context` 的用例只在参考 profile 中替换为该用例的合成冲突上下文，不读取真实窗口或个人词典。

- 原有关键字断言只能检查部分要素；“这不是故障，也不是正常现象”和擅自添加“否则会导致永久丢失”曾被放行。
- 对上述关键场景及新中文用例，使用有限的允许表达集合，规范化空白和常见正文标点；保留小数点、符号、百分号等数字事实字符。错误极性、遗漏限定、擅自扩写及错误改口标记不能仅靠关键字命中通过。
- 允许表达集合是用例级的保守验收，不能当成通用语义评分。未列入但合理的表达需人工复核后补充集合；不能为了提高通过率放宽到仅包含关键词。
- 纯赘词的空正文是预期错误契约，报告单独统计 `expected_empty_errors`，不计为可注入正文；非法 JSON、缺字段、错误类型仍失败。普通有意义短回应返回空文本仍判不通过。
- 普通排版选择只影响固定 Prompt，不增加客户端替换逻辑。
- PRD 允许枚举保守输出为普通正文，也允许整理为列表；旧用例不再仅因 `plain_text` 形态判失败。两种形态均检查信息完整及顺序，列表仍须保留前言、后置补充及正确条目数。

## 对照方法

冻结包含未提交 #38 修复的 Provider 源文件作为基线，避免直接用 HEAD 丢失本地已验证规则。评审时基础提示词 SHA-256 为 `55f55502cc65f57ff4357b4be7009ac1d552fb90e3f66009072a4ca8f2652547`。

```sh
python3 -m unittest discover -s scripts/tests -p test_evaluate_polish_prompts.py
python3 scripts/evaluate-polish-prompts.py --run --suite chinese --versions both \
  --baseline-source /tmp/memoecho-39-baseline-LLMProvider.swift --output /tmp/memoecho-39-comparison.json
python3 scripts/evaluate-polish-prompts.py --reassess /tmp/memoecho-39-all-bare-final.json \
  --output /tmp/memoecho-39-all-bare-reassessed.json
```

第二条命令显式发起真实配置模型请求，可能产生调用费用。只使用合成样例和参考；脚本仅读取连接配置到内存，输出不含凭据、服务地址和模型身份。与既有脚本一样使用 `thinking: disabled`，不模拟生产兼容回退。网络／协议失败需保留，不得重试筛掉失败后宣称全通过。

`--reassess` 只按当前断言离线复核已保存响应，不读取凭据、不发请求；保留 `previous_assessment` 和原内容供审计。该路径有无网络／凭据访问的回归测试。
