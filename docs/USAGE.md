# 使用说明


### 首次准备

首次启动会打开独立欢迎页，以聊天输入框演示唤起语音、Thinking 处理和文字填入；点击“开始设置”进入五步引导：

1. `1 / 5` 选择识别方式：本地 `SenseVoice` 下载模型，或填写现有云端平台配置并验证。本地模型下载成功后才能继续。
2. `2 / 5` 连接 AI 模型：填写 `Base URL`、`API Key`、`Model` 并验证；模型列表不可用时仍可手动输入。
3. `3 / 5` 系统权限：授予麦克风和辅助功能权限。
4. `4 / 5` 全局快捷键：接受默认的右 Command 键，或录制并成功注册新快捷键；点击“完成设置”后即可在其他应用使用。
5. `5 / 5` 设置完成：可直接点击“开始使用”结束引导，也可先试一句。进入已就绪的本页时自动聚焦测试框，提示当前快捷键；按一次说话，再按一次结束，识别并整理后的文字直接回填本页。

首次设置未完成时菜单栏不提供“设置”，重启会续接向导，关窗后按快捷键可重开。第 4 步完成后，菜单栏提供“设置”；向导入口始终不在菜单栏。权限被撤销、模型丢失或配置失效时，下一次快捷键会打开对应设置页，完成修复后不会自动录音。

MemoEcho 使用 `me.wangmao.memoecho` 作为应用标识，配置与个人词典存储于 `~/.memoecho/`。

### 日常使用

1. 在任意应用中聚焦一个可输入文本的位置。
2. 按一次全局快捷键开始录音。
3. 说完后再按一次快捷键结束录音。录音过程中不限时长，应用会自动按静音间隔或 55 秒上限切段，并在后台提前识别已完成的分段。
4. MemoEcho 会依次完成降噪、分段识别、AI 润色，并把最终文本写回当前应用。
5. 如果本次写入失败或无法确认，菜单栏会保留一段截断预览，点击即可复制完整文本。提示无法确认时，请先检查原输入框，避免重复粘贴。
6. 如需更新，可在关于页勾选 `自动检查更新` 或点击 `检查更新`；新版本会通过应用内更新流程下载并安装。

输出绑定录音开始时的输入框；切换到其他输入框后不会自动改投新位置。临时剪贴板会在写入确认或等待窗口结束后恢复，期间新复制的内容优先保留。部分应用不开放可读正文，粘贴后仍可能提示无法确认。

### 失败后继续处理

识别、整理或翻译失败后，可在 HUD 或菜单栏点击对应“重试”，从失败阶段继续，无须重新说一遍。配置问题可先检查设置，修复后手动重试。写入已经尝试但结果不明时只提供复制，请先检查原输入框。

仅在内存保留最近一次可恢复失败，首次失败后 10 分钟过期；重试失败不续期。成功、丢弃、取消恢复或退出会清除记录，不保存录音历史。新的可恢复失败会替换旧记录。

### 麦克风检查

设置 → 语音可选择麦克风、查看实时电平。离页、关闭窗口或开始正式录音时停止电平监听，不缓存音频。正式录音中，持续无声会提示检查麦克风；设备断连或音频流异常会停止录音，可手动继续处理已录内容。

### 窗口上下文与隐私

默认使用当前聚焦窗口辅助 AI 消歧：可见文字最多 10000 字，选区及光标前后各最多 1000 字，并附带应用/窗口信息和清理后的网页地址。这些信息会发送至你配置的 AI 服务。

“设置 → 通用 → 参考窗口上下文”默认开启，可关闭。关闭时新会话不采集窗口上下文，后续整理、翻译和重试请求不再发送已有快照。密码/认证/密钥输入、密码管理器和终端场景不发送正文、标题或网址；网址会移除凭据、查询参数和片段。不截图、不读取其他窗口，上下文不落盘、不写原文日志，失败恢复最多在内存保留 10 分钟。重试继续使用原输入环境的快照，并再次应用内置敏感规则。

### 自动学习词条

词典页可按“全部 / 自动添加 / 手动添加”筛选，配合搜索查看词条。更多菜单支持 UTF-8 CSV 导入、导出：无表头，每行一个词；导出全部词条，导入词统一归为手动添加，已有自动词会转为手动，手动重复词跳过。

普通听写写入后，MemoEcho 会在同一输入框内短时观察本次文本的纠正，编辑稳定后学习完整中英文专名。蓝点标记自动学习词；可在词典页编辑或删除，也可从菜单栏撤销最近一次学习。删除仅移除当前词条，后续仍可自动学习。编辑正文仅在当次内存中使用。无法可靠读取输入框或确认写入时跳过学习。
