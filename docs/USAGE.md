# 使用说明

> 实时 ASR 改造正在实施，以下为新的配置方式；五个实时服务及独立 MiMo 尚待真实服务与输入框验收。


### 首次准备

首次启动会打开独立欢迎页，以聊天输入框演示唤起语音、Thinking 处理和文字填入；点击“开始设置”进入五步引导：

1. `1 / 5` 选择识别方式：本地 `SenseVoice` 下载模型，或填写现有云端平台配置并验证。本地模型下载成功后才能继续。
2. `2 / 5` 连接 AI 模型：填写 `Base URL`、`API Key`、`Model` 并验证；模型列表不可用时仍可手动输入。
3. `3 / 5` 系统权限：授予麦克风和辅助功能权限。
4. `4 / 5` 全局快捷键：接受默认的右 Command 键，或录制并成功注册新快捷键；点击“完成设置”后即可在其他应用使用。
5. `5 / 5` 设置完成：可直接点击“开始使用”结束引导，也可先试一句。进入已就绪的本页时自动聚焦测试框，提示当前快捷键；按一次说话，再按一次结束，识别并整理后的文字直接回填本页。

首次设置未完成时菜单栏不提供“设置”，重启会续接向导，关窗后按快捷键可重开。第 4 步完成后，菜单栏提供“设置”；向导入口始终不在菜单栏。权限被撤销、模型丢失或配置失效时，下一次快捷键会打开对应设置页，完成修复后不会自动录音。

MemoEcho 使用 `me.wangmao.memoecho` 作为应用标识，配置与个人词典存储于 `~/.memoecho/`。

### 云端识别

下拉框按厂商分组，云端入口显示“厂商 · 产品”，不追加括号或重复的类型后缀。本地显示“本地 · SenseVoice”，自定义入口显示“OpenAI 兼容”，识别方式在配置说明中解释。服务由用户选择，不会在失败时自动切换。

各产品系列优先展示实时／流式服务，一句话与 HTTP 分段识别放在后面；阿里云优先展示百炼系列，火山优先展示大模型系列。分组内从上到下的顺序如下，表中省略重复的厂商前缀：

| 厂商 | 产品顺序 |
| --- | --- |
| 腾讯云 | 实时语音识别 → 一句话识别 |
| 阿里云 | 百炼实时语音识别 → 百炼语音识别 → 实时语音识别 → 一句话识别 |
| 火山引擎 | 大模型流式语音识别 → 大模型一句话识别 → 录音文件极速版 → 流式语音识别 → 一句话识别 |
| 科大讯飞 | 实时语音转写 → 语音听写 |

非实时入口按停顿或 55 秒上限切段、串行识别并合并结果；实时入口在录音期间持续发送音频。火山引擎的传统与大模型一句话也边录边传，火山这四个入口使用 WebSocket，录音文件极速版使用 HTTP 分段上传。两种方式都要等待完整转写后，再交给 AI 整理和写入。

| 厂商 | 一句话／非实时 | 实时 |
| --- | --- | --- |
| 腾讯云 | 一句话识别：SecretId、SecretKey | 实时识别：额外填写 AppID |
| 阿里云 | 智能语音交互一句话：AccessKey ID、AccessKey Secret、AppKey | 智能语音交互实时：同类凭据，需开通实时产品 |
| 阿里云百炼 | HTTPS 地址、API Key、Model | WSS 地址、API Key、Model |
| 火山引擎 | 录音文件极速版：API Key | 大模型一句话／实时：API Key、模型版本；传统一句话／实时：AppID、Access Token |
| 科大讯飞 | — | 语音听写 IAT：AppID、API Key、API Secret；实时语音转写 RTASR：AppID、独立的 RTASR API Key |

共享的凭据只需填写一次，各服务分别验证；验证过一句话不代表实时已就绪。讯飞 IAT 与 RTASR 密钥分别保存，百炼非实时与实时配置也分别保存。

修改相关连接字段后需重新验证。验证不会录制麦克风；实时、百炼 HTTP、MiMo 与 OpenAI 兼容使用内置合成语音，腾讯云与阿里云的一句话入口沿用上一版测试音频与验证方式。请先确认对应产品已开通。

### 火山引擎

火山分组从上到下为“大模型流式语音识别”“大模型一句话识别”“录音文件极速版”“流式语音识别”“一句话识别”。文件极速版保留历史平台标识与 API Key，旧配置仍选择该入口，无需重新填写；已保存为本地的配置不会自动改回。

“录音文件极速版”只填写 API Key，与两个大模型入口共享 Key，分别验证。它通过 HTTP 分段上传音频，不使用实时模型的 1.0／2.0 选项；需开通文件极速版产品。

“一句话识别”与“流式语音识别”是传统产品，只需填写 AppID、Access Token。AppID、Token 共享，两个产品分别开通、分别验证，集群路由由应用自动选择，不需要填写 Cluster 或 Access Secret。两个产品都在录音期间上传音频，使用传统 V2 WebSocket 接口。

“大模型一句话识别”与“大模型流式语音识别”填写 API Key，优先使用账号已开通的模型 2.0，使用 V3 WebSocket 接口。前者是流式输入模式的界面简写，后者使用双向流式模式。新配置及没有保存模型版本的配置默认 2.0，版本选项优先显示 2.0；已有明确保存的 1.0 选择保留，修改模型后需要重新验证这两个产品。

传统与大模型凭据不互用，每项分别验证。长录音会自动续接原生会话，整次录音仍由快捷键手动结束；最终完整转写后再交给 AI。

### 科大讯飞

选择“科大讯飞 · 语音听写”使用 IAT 流式版（`wss://iat-api.xfyun.cn/v2/iat`），填写 AppID、IAT API Key 和 API Secret。音频在录音期间按 40ms 帧持续发送，支持动态修正。长录音按 55 秒服务会话续接，长静音主动轮换会话，整次录音可继续；只有完整结果才交给 AI。原“一句话”选中值会改选该入口，已有 IAT 凭据保留，但需重新验证。

选择“科大讯飞 · 实时语音转写”使用 RTASR（`wss://rtasr.xfyun.cn/v1/ws`），填写 AppID 和 RTASR API Key。两个产品各自开通、各自验证，密钥不能互用。验证均发送内置合成语音。

### OpenAI 兼容

在语音引擎中选择“OpenAI 兼容”，填写支持 Audio Transcriptions 的 Base URL 和 Model。API Key 在服务不要求鉴权时留空，与 AI 设置中的 Key 独立。Base URL 通常以 `/v1` 结尾，也可直接填写 `/audio/transcriptions` 完整地址。

本地示例：`http://localhost:8000/v1`，Model 按部署情况填写 `Qwen3-ASR-0.6B-4bit` 或 `Qwen3-ASR-1.7B-4bit`。另一台机器部署时将 localhost 换为其局域网地址。本机、私网 IP 和 `.local` 主机支持 HTTP 明文；公网服务使用 HTTPS。首次访问局域网时需允许 macOS 本地网络权限，可在“系统设置 → 隐私与安全性 → 本地网络”中开启。

这个入口仍按分段上传 WAV，不提供实时音频接口。旧 Chat Completions 配置会显示停用原因，需要手动重新配置；不会自动转换请求或导入 MiMo。

填写后发送随包合成语音验证。本地模型首次加载可能较慢，超时后可待服务加载完成再重试。本地 ASR 的转写仍会交给所配置的 AI 服务整理，不代表整条流程都在本机运行。

### 小米 MiMo

选择独立的“小米 · MiMo”入口，手动填写 Base URL、API Key 和 Model。默认地址为 `https://api.xiaomimimo.com/v1`，默认模型为 `mimo-v2.5-asr`；Token Plan 用户填写自己套餐对应的地址和凭据。

MiMo 通过 Chat 音频协议按分段识别，是五个云厂商实时化范围外的独立入口。它不与 OpenAI 兼容或 AI 设置共享凭据。历史两个小米入口不做兼容或迁移，也不会自动导入此前 OpenAI Chat 配置中的 Key。仍选中旧小米平台的配置会读取失败并保留原文件，需手动修正；错误状态下直接保存设置会重建整份配置。

### 阿里云百炼

“阿里云 · 百炼实时语音识别”入口使用原生实时 WebSocket 服务，默认地址为 `wss://dashscope.aliyuncs.com/api-ws/v1/inference`，默认模型为 `paraformer-realtime-v2`。Model 可自由填写，不设模型白名单；模型名称非空即可进入真实请求验证，服务端须完成识别后才就绪。所填模型仍需支持此接口的任务式实时协议。填写对应地域的 API Key 和 WSS 地址；地址必须以 `/api-ws/v1/inference` 结尾，不能包含用户名、密码、查询参数或片段。

“阿里云 · 百炼语音识别”入口使用 HTTPS 同步接口，支持填写 `/api/v1` 基础地址或 `/api/v1/services/aigc/multimodal-generation/generation` 完整地址。默认模型为 `qwen-audio-3.1-asr-flash`，模型可自由填写。请求使用 `input.messages[].content[].input_audio.data` 提交 WAV Data URL，并读取 `output.text`；模型须支持该协议。协议参考[百炼 HTTP 文档](https://help.aliyun.com/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)。

两个入口不能互用 HTTPS/WSS 地址，不会自动转换配置。阿里云智能语音交互保留独立的“阿里云 · 实时语音识别”和“阿里云 · 一句话识别”入口，与百炼配置不共用。实时音频直接发送给所选服务，不保存录音历史。

### 日常使用

1. 在任意应用中聚焦一个可输入文本的位置。
2. 按一次全局快捷键开始录音。
3. 说完后再按一次快捷键结束录音。云端实时入口和火山一句话入口在录音时持续上传音频；腾讯云与阿里云的一句话识别、火山录音文件极速版、百炼 HTTP、本地 SenseVoice、OpenAI 兼容和 MiMo 按静音间隔或 55 秒上限切段，并在后台识别。
4. MemoEcho 在识别结果完整后进行 AI 润色，把最终文本一次写回当前应用。实时中间结果不会直接写入输入框。
5. 如果本次写入失败或无法确认，菜单栏会保留一段截断预览，点击即可复制完整文本。提示无法确认时，请先检查原输入框，避免重复粘贴。
6. 如需更新，可在关于页勾选 `自动检查更新` 或点击 `检查更新`；新版本会通过应用内更新流程下载并安装。

输出绑定录音开始时的输入框；切换到其他输入框后不会自动改投新位置。临时剪贴板会在写入确认或等待窗口结束后恢复，期间新复制的内容优先保留。部分应用不开放可读正文，粘贴后仍可能提示无法确认。

### 失败后继续处理

识别、整理或翻译失败后，可在 HUD 或菜单栏点击对应“重试”，从失败阶段继续，无须重新说一遍。配置问题可先检查设置，修复后手动重试。写入已经尝试但结果不明时只提供复制，请先检查原输入框。

云端实时失败只保留已确认文本与尚未确认的有界音频，不自动重连或重发。手动恢复后仍需等待完整结果；取消或结果不完整时不会注入。

仅在内存保留最近一次可恢复失败，首次失败后 10 分钟过期；重试失败不续期。成功、丢弃、取消恢复或退出会清除记录，不保存录音历史。新的可恢复失败会替换旧记录。

### 麦克风检查

设置 → 语音可选择麦克风、查看实时电平。离页、关闭窗口或开始正式录音时停止电平监听，不缓存音频。正式录音中，持续无声会提示检查麦克风；设备断连或音频流异常会停止录音，可手动继续处理已录内容。

### 窗口上下文与隐私

默认使用当前聚焦窗口辅助 AI 消歧：可见文字最多 10000 字，选区及光标前后各最多 1000 字，并附带应用/窗口信息和清理后的网页地址。这些信息会发送至你配置的 AI 服务。

“设置 → 通用 → 参考窗口上下文”默认开启，可关闭。关闭时新会话不采集窗口上下文，后续整理、翻译和重试请求不再发送已有快照。密码/认证/密钥输入、密码管理器和终端场景不发送正文、标题或网址；网址会移除凭据、查询参数和片段。不截图、不读取其他窗口，上下文不落盘、不写原文日志，失败恢复最多在内存保留 10 分钟。重试继续使用原输入环境的快照，并再次应用内置敏感规则。

### 自动学习词条

词典页可按“全部 / 自动添加 / 手动添加”筛选，配合搜索查看词条。更多菜单支持 UTF-8 CSV 导入、导出：无表头，每行一个词；导出全部词条，导入词统一归为手动添加，已有自动词会转为手动，手动重复词跳过。

普通听写写入后，MemoEcho 会在同一输入框内短时观察本次文本的纠正，编辑稳定后学习完整中英文专名。蓝点标记自动学习词；可在词典页编辑或删除，也可从菜单栏撤销最近一次学习。删除仅移除当前词条，后续仍可自动学习。编辑正文仅在当次内存中使用。无法可靠读取输入框或确认写入时跳过学习。
