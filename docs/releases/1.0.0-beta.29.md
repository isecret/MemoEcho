# 1.0.0-beta.29 发布与验证

状态：已发布。显示版本 `1.0.0-beta.29`、内部构建号 `1.0.0b29`、标签 `v1.0.0-beta.29`。用户已授权提交本地改动、发布新测试包并同步官网及软件源；真实语音和跨模型／应用验收仍按实际记录，不因发布测试包自动关闭 Issue。

## 本次更新

- 改善连续口述中“然后、就是”等接话词与普通重复的清理，覆盖句中、标点分隔及连续分段边界，保留实际操作顺序和有效内容。
- 整理同一名词前后的重复指代、枚举中的助词及拖沓结构，减少仅添加标点却保留口头赘词的情况。
- 无意义语气缀词覆盖“啊、呀、嘛、呢、呐、啦”等，包含句尾拖尾；有意义的回应、提醒、疑问、不确定性、引用和词内字符继续保护。
- 保留“只、可能、现在”等限定、否定和条件，不猜补省略主语；已有数字内的小数点、千分位逗号和单位保持原样。
- 连续操作、数据名词和只介绍第一种方案时保持普通正文；明确逐项枚举仍可使用列表，不为凑数量生成空项或补写方案。

关联 [#41](https://github.com/isecret/MemoEcho/issues/41)，延续 [#39](https://github.com/isecret/MemoEcho/issues/39) 与 [#38](https://github.com/isecret/MemoEcho/issues/38)。实现仅调整固定润色 Prompt 和合成评测，不增加用户配置、生产正则删词或额外模型请求，不改变协议、重试及文本注入策略。
