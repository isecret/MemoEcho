# 1.0.0-beta.28 发布与验证

状态：准备发布。显示版本 `1.0.0-beta.28`、内部构建号 `1.0.0b28`、标签 `v1.0.0-beta.28`。用户已授权提交代码、发布新测试包，并同步软件源和官网链接。该授权不表示所有真实语音、外部应用、模型和设备组合均已验收。

## 本次更新

- 修复 Thinking 阶段按 Esc 无法取消任务的问题，覆盖识别、润色、翻译和自动重试等待；取消后阻止迟到结果继续推进或写入。
- 改善同一次语音中重叠、接续和补充表达的合并，单段与连续分段使用一致规则，保留有效信息和独立含义。
- 优化明确反悔式改口、情绪重复与中文语义保真边界，保留否定、条件、对象、时间、数字、单位和不确定程度，不替用户补全未完成句。
- 纯无语义停顿清理后没有有效正文时，沿用现有空结果错误，不注入、不自动重试，保留转写供手动恢复；独立“嗯”等回应仍保留。
- 普通“换行、逗号、加引号”等口述仍作为正文，不新增排版命令；已有技术符号还原、普通重复去重、列表和安全渲染继续保留。

关联 [#37](https://github.com/isecret/MemoEcho/issues/37)、[#38](https://github.com/isecret/MemoEcho/issues/38)、[#39](https://github.com/isecret/MemoEcho/issues/39)。详细口径和评测记录见[中文润色语义边界](../plans/chinese-polish-boundaries.md)。相关 Issue 的真实语音及系统按键手工验收仍保留，不因发布测试包自动关闭。
