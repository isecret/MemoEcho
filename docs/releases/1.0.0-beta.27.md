# 1.0.0-beta.27 发布准备与验证

状态：发布准备中。显示版本为 `1.0.0-beta.27`，内部构建号为 `1.0.0b27`，计划标签为 `v1.0.0-beta.27`。用户已确认当前本地测试版效果可以，并授权发布新的测试包、更新官网和软件源；此确认不扩展为所有模型、设备、外部服务或原始升级故障场景均已验收。

## 本次更新

- 更好地还原口述文件名、网址、邮箱和明确路径，例如“点 ENV”得到 `.env`，“p 点 example 点 com”得到 `p.example.com`。不会补出未说的协议、后缀或路径。
- 网址中明确说出的协议名统一小写，例如 `HTTPS://www.example.com` 整理为 `https://www.example.com`；路径、参数、片段和普通文件名的已有大小写保留。
- 清理没有回应含义的句首“嗯”，合并“好的好的”等普通回应重复；正常叠词、明确强调、引用和独立回应仍保留。
- 修复启动验证的临时失败被长期缓存为“未就绪”的问题。首次检查与后续复测共用有限重试预算；持续临时故障显示“暂不可用”，配置、鉴权与服务端限流保护继续生效。
- 补充实时连接的代理、握手、阶段耗时及受控错误诊断，不记录正文、凭据、服务地址或代理节点。

使用示例见[使用说明](../USAGE.md#文件名网址与口头重复)，详细边界见[口述技术文本方案](../plans/technical-dictation.md)与[模型就绪排查及修复](../validation-model-readiness.md)。关联 [Issue #33](https://github.com/isecret/MemoEcho/issues/33)、[Issue #34](https://github.com/isecret/MemoEcho/issues/34)，不在本记录中自动关闭。
