# 1.0.0-beta.31 发布与验证

显示版本为 `1.0.0-beta.31`，内部构建号为 `1.0.0b31`，发布标签为 `v1.0.0-beta.31`。用户于 2026-11-11 授权发布后台更新提醒修复，并同步软件源和官网。当前等待远端构建及分发核验。

## 本次修复

后台自动检查发现新版本时显示带徽标的 Dock 图标，为菜单栏应用提供可见的更新提醒。点击 Dock 可将已有更新窗口带到前台；用户关注更新后清除徽标，更新会话结束后根据设置／引导窗口状态恢复 Dock 显示。

更新、设置和引导共用窗口入口管理，覆盖更新期间关闭设置、更新结束后保留设置等情况。现有更新会话期间可通过设置中的检查更新入口再次打开窗口。跟踪 [Issue #45](https://github.com/isecret/MemoEcho/issues/45)。

## 发布前验证

- 定向 XCTest 19 项通过，覆盖自动与手动检查、提醒关注与清理、系统 reopen 路由、窗口并存及 Debug 更新禁用。
- 独立原生 QA 使用生产服务和窗口入口代码执行真实 Sparkle 后台定时检查。修复前出现后台更新窗口但无 Dock 提醒；修复后出现 Dock 徽标，应用保持后台。
- 用户解锁桌面后，经系统重开入口验证原应用委托与 Sparkle 更新器能够将已有更新窗口变为 key window、激活应用并清除徽标。点击稍后提醒也已验证关闭与清理。
- 上述原生 QA 覆盖更新发现、提醒、聚焦与关闭流程；公开包的下载安装和替换升级另按实际执行记录。
