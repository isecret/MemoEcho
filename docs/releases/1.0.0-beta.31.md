# 1.0.0-beta.31 发布与验证

状态为已发布。显示版本为 `1.0.0-beta.31`，内部构建号为 `1.0.0b31`，发布标签为 `v1.0.0-beta.31`。用户于 2026-11-11 授权发布后台更新提醒修复，并同步软件源和官网。公开安装包、官网、Sparkle 与 Homebrew 分发核验均通过。

## 本次修复

后台自动检查发现新版本时显示带徽标的 Dock 图标，为菜单栏应用提供可见的更新提醒。点击 Dock 可将已有更新窗口带到前台；用户关注更新后清除徽标，更新会话结束后根据设置／引导窗口状态恢复 Dock 显示。

更新、设置和引导共用窗口入口管理，覆盖更新期间关闭设置、更新结束后保留设置等情况。现有更新会话期间可通过设置中的检查更新入口再次打开窗口。跟踪 [Issue #45](https://github.com/isecret/MemoEcho/issues/45)。
