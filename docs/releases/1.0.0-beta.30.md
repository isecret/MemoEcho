## 本次修复

修复应用启动后第一次长按快捷键、松开无法结束录音的问题。首次语音输入会检查辅助功能权限，确认已授权时的回调重新注册快捷键，清除了仍在进行的长按。权限回调现在识别与当前配置一致的有效长按，并保留该次监听，使松开能够结束其启动的录音。注册失败后的权限恢复继续尝试注册。

跟踪 [Issue #43](https://github.com/isecret/MemoEcho/issues/43)。

## 验证

- 修复前的协调器回归收到 `holdBegan`、`holdCancelled`，缺少 `holdEnded`，复现松开无法结束录音。
- 修复后相同入口收到 `holdBegan`、`holdEnded`，短录音回到 `idle`。另一项回归覆盖首次注册失败后授权成功的重新注册。
- 本地快捷键及权限定向 XCTest 74 项通过。全量 XCTest 970 项，9 项按既有环境条件跳过，0 失败。
- Debug 包已启动并确认进程路径。首次长按通过模拟按键验证，真实键盘与完整语音输入手工验收待确认。
